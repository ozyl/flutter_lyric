Lyric compositing measurements -- 2026-10-11 (Asia/Shanghai)

Baseline: 4b3bf6c
Candidate: single-layer color-filter composition + fade shader reuse
Environment: Flutter 3.44.8 / Dart 3.12.2, macOS 26.6.2 arm64,
             Microsoft Edge 155.0.4283.45 (CanvasKit)

Reproduction
------------
Use the same SDK and dependencies for both revisions. Copy the two benchmark
entry points into a separate checkout of 4b3bf6c to measure the baseline.
Do not run the two benchmarks or other test/build jobs concurrently.

From repository root:
  CHROME_EXECUTABLE='/Applications/Microsoft Edge.app/Contents/MacOS/Microsoft Edge' \
    flutter test --no-pub test/benchmarks/lyric_compositing_benchmark.dart \
    --platform chrome --reporter expanded

From example/ (after resolving its dependencies):
  flutter run --no-pub -d macos --profile \
    -t ../test/benchmarks/lyric_frame_benchmark.dart

Keep the native window visible and unchanged. Quit with q after COMPOSITING done.
Both fixtures use 1,000 lines, translations, a 400 x 600 viewport, changing word
highlight width, fractional scrolling, selection, and repeated index jumps.
They drive paint state directly to isolate rendering; gesture/controller latency
and initial paragraph construction are outside the measured interval.

Decisions backed by pixel checks
-------------------------------
The base color is composed behind each highlight shader sample before applying
neutral glyph coverage once. Non-overlapping color fields use one surface;
overlapping line metrics retain the original two-surface fallback.

The full-viewport ShaderMask is retained. Simply bypassing a zero-range mask
changed 364 channels (maximum delta 46) in the fractional-position CanvasKit
edge fixture, so that experiment was rejected. The final change reuses the
mask shader at stable bounds; new bounds or style build a new shader. Group
fading, including overlapping translucent content, remains intact.

Regression commands
-------------------

  CHROME_EXECUTABLE='/Applications/Microsoft Edge.app/Contents/MacOS/Microsoft Edge' \

Performance entry points intentionally do not end in _test.dart, so the normal
regression suite does not run timing experiments.
